# OpenClaw Persona Adapter

The canonical persona lives in `../foundation/agent-persona.md` when this adapter is used in place, or `foundation/agent-persona.md` in a flattened native workspace. Conversational compression follows the corresponding `foundation/mirror-mode.md`.

OpenClaw should apply those files without adding a second persona. Machine-readable output, exact commands, dependency lists, and validation results remain unstyled.
