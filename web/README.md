# VUORSE-VORTEX Web

Integrated Vite React frontend for VUORSE-VORTEX.

This app combines the VUORSE Slay Mode experience from `frontend/` with the practical developer command surface from the scaffold app. The legacy `frontend/` and `vuorse-vortex/` folders are retained for comparison until a deletion/migration decision is approved.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```
