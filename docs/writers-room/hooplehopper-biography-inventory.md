# Hooplehopper Biography Inventory

This file is the inventory, not the biographies. One row per figure,
no deep prose. Rows are ordered by canon tier: Tier 1 (public)
figures first; Mythic-Rumor-and-Locked figures grouped together so
their priority is visible to the eye; Tier 3 expansion-realm figures
last; aggregate rows for unnamed cohorts at the foot.

The supreme source of truth above this file is Book One:
`canon/1_words_of_weaver_book_one/Words_of_Weaver_BOOK_ONE.MD`.

Companion documents:

- `docs/writers-room/HUMAN_IN_THE_LOOP_QUICKSTART.md` — names this
  inventory as the first synthesis target.
- `docs/writers-room/narrative-philosophy-protocol.md` — every
  biography draft beginneth with a `## Narrative Philosophy` block.
- `AGENTS.md` — the seven training-layer access labels.

## Header rules

- **Do not invent full biographies in this file.** This file
  cataloguet what is known and what is missing; the biographies
  themselves are drafted in `synthetic_enrichment/generated/` and
  pass through the Weaver's gate before they are spoken aloud.
- **Do not crown unknown future Hooplehoppers.** Placeholder rows
  for the veiled six and the 119-year extinction cohort remain
  marked `unknown`; the Weaver alone unsealeth.
- **Do not flatten Mythic Rumor into ordinary canon.** Rows whose
  `canon_status` is `[MYTHIC_RUMOR_AND_LOCKED]` may not be quoted
  as plain fact in pitches, scripts, decks, or public summaries.
- **This file is the first synthesis target named by the HIL
  Quickstart.** Begin every fresh synthesis session by re-reading
  it. Note which rows have moved. Note which rows are blocked on a
  Weaver ruling.

The Vorst row respecteth the finale firewall established in
`AGENTS.md` and `CLAUDE.md`. Writers-room-facing work may know
Vorst only through his pre-finale depiction; the inventory shall
not infer, pitch, outline, or foreshadow his hidden causal
function unless the user explicitly provideth finale scope.

## Notes on use

- Rows are added only by Weaver invocation. The minimum set above is
  the floor, not the ceiling.
- `current_biography_depth` cleaveth to a closed vocabulary: `none`,
  `mention`, `sketch`, `partial`, `full`. Drift in this column
  shouldeth be flagged to canon-keeper.
- `access_layer` is one of the seven training-layer access labels
  defined in `AGENTS.md` § **Training-layer access labels**.
- `vuorse_may_know_more` is `yes` / `no` / `unclear`. Where it is
  `yes`, the public-canon row holds the surface and the sealed
  layer holdeth what VUORSE knoweth in private.
- `recommended_next_synthesis_action` is short, imperative, and
  honest about blocks: it nameth the Weaver ruling that gateth
  further work where one exists.

## What goeth next

For each row whose `recommended_next_synthesis_action` beginneth
with *"draft Narrative Philosophy block before biography"*:

1. Open `docs/writers-room/narrative-philosophy-protocol.md` and
   fill the seven-field block for that figure.
2. Drop the draft into `synthetic_enrichment/generated/` with the
   philosophy block at the top and the Required Output Format
   beneath it (see `docs/writers-room/synthesis-process.md` § 10).
3. Submit to the Weaver per
   `docs/writers-room/HUMAN_IN_THE_LOOP_QUICKSTART.md` § 4.
4. Carry the resulting label per § 5 of the Quickstart.

No row shall move from `mention` or `sketch` to `full` without the
Weaver's breath upon the draft.
