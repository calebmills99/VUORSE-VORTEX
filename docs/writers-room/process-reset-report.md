## 3. Process Changes

- **Supreme doctrine.** Book One is now the controlling text above
  `CLAUDE.md`, `AGENTS.md`, and every agent prompt.
- **Submission line.** Every synthesis artifact must open with a
  *Controlling Weaver Doctrine* citation by chapter and verse, or stop.
- **Seven-tier Canon Hierarchy.** Replaces the prior four-house model.
  Mythic Rumor That Is Also Locked Canon is now an explicit Tier 2.
- **Nine-rung Synthesis Ladder.** Synthesis must climb detail →
  contradiction → living-canon integration → mythic implication →
  emotional wound → symbolic system → season function → series
  consequence → JSONL.
- **Required Output Format.** Eleven doctrinal headings plus a twelfth
  operational tail (*File Updates Required*) are mandatory for every
  future synthesis output. The sample synthesis persists the canonical
  worked example.
- **Plan-size limits.** Traycer may not author plans exceeding three
  tickets or two Weaver questions per pass.
- **Anti-overreach.** No agent may declare canon status, resolve a
  contradiction, unseal a Tier-2 truth, or author finale doctrine. All
  such moves route to the Weaver.

## 4. Agent Behavior Changes
