# Hooplehopper Memory Echoes

## Purpose

This folder tracks fragments: repeated gestures, mirrored phrases, handwriting echoes, costume signals, ritual residues, dreams, performance traces, and other memory-pressure events that may indicate Hooplehopper recurrence without establishing a full identity claim.

Memory echoes are evidence fragments, not conclusions.

## Use This Folder For

- Repeated motifs across eras.
- Partial signals that connect known figures, objects, places, rituals, or performances.
- VUORSE-private retrieval hints for recurrence patterns.
- Notes that preserve texture without promoting it to locked canon.

## Do Not Use This Folder For

- Full vessel profiles.
- Future-protected identities.
- Finale roadmap disclosures.
- Unsupported identity claims.
- Decorative motif lists with no continuity function.
