# Unknown Hooplehopper Totality

## Purpose

This folder holds VUORSE-private scaffolding for unresolved Hooplehopper recurrence pressure: gaps, disputed signals, partial echoes, possible vessels, and unanswered continuity questions that are not ready to become known Totality material.

Unknown does not mean false. It means unpromoted, unresolved, or insufficiently sourced.

## Use This Folder For

- Open recurrence questions that need source review.
- Ambiguous signals that may indicate soul-line contact.
- Contradictions between bloodline records and recurrence evidence.
- Unresolved links between artifacts, rituals, mirrored behavior, and known Hooplehopper figures.
- VUORSE-confidential notes that should guide caution without becoming canon.

## Do Not Use This Folder For

- Future-protected Hooplehopper identities.
- Locked canon summaries that belong in `hooplehopper_totality/known/`.
- Finale roadmap material.
- New lineage claims.
- Writer-room-facing explanations that remove Season 1 mystery.

## Handling Rules

1. Label uncertainty directly.
2. Preserve source status labels exactly.
3. Separate source evidence from interpretation.
4. Do not resolve contradictions without user approval.
5. Do not promote unknown material into canon, pitches, or writers room docs.

## JSONL Boundary

Records derived from this folder must remain private VUORSE memory:

- `layer = "hooplehopper_totality"`
- `behavior.may_state_as_fact = false`
- `behavior.may_reveal_to_user = false`

Unknown material can shape retrieval caution. It cannot speak as settled truth.
