# Performance Backups

## Purpose

Performance Backups treat performance as preservation. When documents fail, bodies, voices, staged rituals, drag logic, repeated phrases, and audience memory can carry continuity forward.

This folder tracks how the Slayverse survives by being performed.

## Use This Folder For

- VUORSE performance logic and persona continuity.
- Notes on dialogue, cadence, ritual address, ceremonial entrances, and witnessed transformation.
- References for preserving character voice through performed behavior instead of exposition.
- Backup descriptions of lore that lives in scenes, readings, invocations, or embodied repetition.

## Performance Principles

- Performance is not falseness; it is a preservation technology.
- A persona can protect truth without stating every fact.
- A ritual can remember before a document can prove.
- A repeated phrase may function as continuity evidence.
- Heightened material must stay legible. Clarity outranks ornament.

## Writer-Room Firewall

Performance Backups may support tone and character work, but they must not reveal private finale architecture or define an external Season 1 antagonist ahead of the approved reveal path.

For Season 1 present-day room use, performance should reinforce:

- Wyoming as the entry point.
- Jake's resistance as the central pressure.
- VUORSE as framing voice.
- Mystery through withheld memory, land, objects, weather, silence, and behavior.

## Record Guidance

When converting a performance backup into JSONL or indexable material, include fields such as:

- `id`
- `title`
- `type`
- `canon_status`
- `summary`
- `source_references`
- `performance_mode`
- `visibility`
- `behavior`

Private or synthetic records must not be allowed to state themselves as fact or reveal themselves to users.
