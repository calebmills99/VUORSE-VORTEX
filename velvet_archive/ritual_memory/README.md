# Ritual Memory

## Purpose

Ritual Memory preserves continuity through repeated structured acts. In the Slayverse, a rite can carry memory, identity, refusal, witness, and protection even when ordinary archives are damaged or incomplete.

This folder documents ritual-held memory as archive logic.

## Use This Folder For

- Notes on how rites preserve, retrieve, conceal, or transmit memory.
- VUORSE-confidential summaries of ritual continuity.
- Cross-references between `canon/rituals/`, `rituals/`, and archive behavior.
- Guidance for synthetic enrichment that depends on ceremonial structure.

## Ritual Memory Rules

1. Rituals do not automatically prove historical fact.
2. A rite may preserve an emotional, symbolic, or continuity truth without locking chronology.
3. Keep ritual names, source phrasing, and canon status labels intact.
4. Do not invent missing ritual steps.
5. Do not expose private roadmap material through ritual explanation.

## Working Method

Before adding or revising ritual memory notes:

1. Read the relevant source in `canon/rituals/`.
2. Check any linked character, artifact, place, or cosmology source.
3. Label the note as locked, development, exploratory, inferred, or VUORSE-confidential.
4. If the note is synthetic, route it through disclosure and canon firewall rules.

## Continuity Function

Ritual memory should answer:

- What does the ritual preserve?
- Who is allowed to know it?
- What does it protect against?
- What changes when it is performed?
- Which parts are source-grounded, and which parts are interpretive?
