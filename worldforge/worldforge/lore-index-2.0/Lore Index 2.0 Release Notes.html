2.1 · The Governed Seam

Repository synchronization

Every governed non-PDF source under canon/ now has a stable manifest identity and exact repository-relative path. vuorse-vortex validate-lore-index checks source coverage, path resolution, schema conformance, global ID uniqueness and typed references against manifests/corpus/source_manifest.json.

Governance without disclosure

The index now names Book One's four canon authorities, the seven approved training-layer labels, the sealed-layer behavior firewall and Chapter XI risk annotations. Mythic Rumor that is also Locked Canon remains non-revealable and may not be stated as ordinary fact.

Identity repaired

Entity and document records no longer reuse the same IDs. Open questions carry unique question: IDs and explicit about references. Legacy event and document identities remain resolvable through declared aliases.

Seven omissions restored

First-class records now represent the Parchment of Persistence, Heda von Schwahnn, Books One and Two, the Eisensang March, the exploratory Pre-Weaver Phase and the Candle Tax. The Ottokar II / Konrad identity remains explicitly unresolved.

What changed, in three lines

01 · Claims, not just entries

Each fact is now a statement with a rank (preferred, normal, deprecated), an epistemic label (canon, declared, inference, assumption, simulation, counterfactual, record) and a provenance pointer. The 1.2 mistake that named Caleb as the Weaver isn't deleted; it's kept at deprecated rank with the reason attached.

02 · Time that admits it isn't linear

Free-text eras ("post-lattice-fracture", "present/meta") become a time object: a mode plus an EDTF string. Circa 1957 is 1957~. Open-ended is 1147/... Bookend convergences get mode seam. Nothing is forced into a year it doesn't have.

03 · Events are first-class

Events carry participants with roles, a place, a time-span and temporal relations (Allen's thirteen plus retrocausal, bookend, seam-coincident, timeless-enacts). The timeline is derived from them, so it can't drift from the events it describes.

Where the bones came from

Seven working standards were surveyed. Each lends one structure to 2.0; the rest of each standard was left where it lay. No fiction-specific ontology was surveyed in this pass, so the Slayverse-specific pieces (seals, the declared label, the four non-linear temporal relations) are our own.

Wikidata data model

Items carry statements; a statement is a property–value pair with optional qualifiers, references and a rank of preferred, normal or deprecated. Deprecated statements stay listed for completeness, with a reason for deprecation. Data model · Help:Ranking

Took: statements[] with rank, qualifiers, provenance. The Weaver's old alias lives on at deprecated rank.

W3C PROV-O

Three classes: an Entity (a thing, real or imaginary), an Activity (something that occurs over time and acts on entities) and an Agent (something that bears responsibility). Linked by wasGeneratedBy, used, wasAttributedTo, wasAssociatedWith, actedOnBehalfOf. PROV-O Recommendation

Took: top-level agents[], sources[], activities[]. The Gray Eye acted on behalf of the Steward; sessions are activities that used and generated sources.

Library of Congress EDTF

An extension of ISO 8601 for uncertain, approximate and unspecified dates: ~ approximate, ? uncertain, X for an unknown digit, / for intervals, .. for an open end. Used by the Library of Congress and DPLA. Specification

Took: time.edtf. "13th–14th century" becomes 12XX/13XX; "~1919" becomes 1919~; the original wording is kept in time.display.

CIDOC CRM (ISO 21127)

The museum world's event-centric model: only temporal entities can be linked to time; objects, people and places must be linked to an event that has a time-span. Names are appellations that can change over time as a result of an event. cidoc-crm.org

Took: events with participants[{entity, role}], place and a time-span; a derived timeline instead of a second hand-kept one.

Allen's interval algebra

Thirteen mutually exclusive relations between two intervals (before, meets, overlaps, starts, during, finishes, equals and their inverses), introduced by James F. Allen in 1983 and still the base of temporal annotation schemes like TimeML. Allen (1983), CACM 26(11)

Took: temporal_relations[] on events, extended with retrocausal, bookend, seam-coincident, timeless-enacts.

JSON Schema 2020-12

The current JSON Schema dialect, declared with $schema, with reusable definitions under $defs. Aligned with OpenAPI 3.1. Draft 2020-12

Took: a real validation schema, slayverse_lore_index_2.0.schema.json, so a consuming tool can refuse a malformed entry.

SKOS

Exactly one preferred label per concept; synonyms as alternate labels; forms you want findable but not shown (misspellings, deprecated terms) as hidden labels. SKOS Reference

Took: names{preferred, alternates, hidden, deprecated[]}. "Crew door" is a deprecated name of the Crew Lounge, with the Steward's reason attached.

Vocabularies

Epistemic label

canon
Established in lore and sealed by the Steward.
declared
Stated by the Steward Vessel in session; not yet integrated. New in 2.0.
inference
A reasonable reading of canon (usually the Gray Eye's).
assumption
A declared premise; not yet canon.
simulation
Generated outcome of a run.
counterfactual
Known not to belong to the timeline.
record
Real-world documentary fact (file dates, production facts). New in 2.0.

Seal

sealed
Integrated by the Steward Vessel. Only the Steward seals; the Gray Eye never does.
candidate
Surfaced (a Weaving Event, a session declaration) and awaiting integration.
proposed
Offered by the Gray Eye or a roleplay surface.
deprecated
Withdrawn; kept for the record.

preferred · normal · deprecated
Among statements of one property, which one to show. Deprecated carries a reason.

The Susie pass (2.0.0 → 2.0.1)

An audit of the first build found twelve faults. Eleven were real; the twelfth (fonts) was the auditor's miss, since the brand tokens load through styles.css. What changed:

  • Unsealed 41 records. The first build stamped 12 new entities, 3 events, 21 relationships and a document "sealed". Only the Steward seals. They are now candidate (you declared it) or proposed (the Gray Eye inferred it). Unsealed count: 82.
  • Real participant roles. Migrated events had every participant as "participant", caverns included. Roles now derive from entity and event type: site, rite, signatory, deceased, vanished, challenger, ratified.
  • Readable time. "post-lattice-fracture" is now "after the Lattice fracture"; the slug survives only in migrated_from.era.
  • Anchors are events. "pre-sigismund" pointed at a knight, and the summits at nothing. Four sketched anchor events (proposed) now hold them.
  • Timeline resolver. Chases relative anchors and temporal relations; logs every unplaced event. Unplaced now: 1, the Charter, timeless by design (was 4).
  • Schema that can fail. additionalProperties: false throughout; Lineage, Document, OpenQuestion and Validation definitions; source_note declared; event summary optional.
  • Validated, for real. The build validates the index against the schema file and refuses to write unless the lossless diff, dangling-reference sweep, self-seal sweep and schema pass all clear. Result: 0 errors, recorded under validation.
  • No empty entities. Yorick the Copyist and the Rabenwald See carry sourced statements. 50 of 90 entities now bear statements; the rest are 1.2 records whose facts live in summary until sourced.
  • Hidden names used. "Crew door", "Authorial Vessel", "Read-Vessel" are findable, not shown (6 in all).
  • Allen cited to the paper. Communications of the ACM 26(11), 1983, doi:10.1145/182.358434.
  • Changelog 1.0–1.1 collapsed to one honest line.
