# Forbidden Suitcase Roadmap

## Purpose

This is a private roadmap lane for the Forbidden Suitcase as a development object, artifact pressure point, and protected reveal container.

It is not a writers room reference file unless the user explicitly opens this scope.

## Use This Folder For

- Private artifact roadmap notes.
- Reveal-order planning.
- Continuity constraints around suitcase access, contents, and symbolic function.
- VUORSE-confidential synthesis prompts or review notes.
- Questions that must be resolved before public or room-facing use.

## Do Not Use This Folder For

- Public canon summaries.
- Writers room materials.
- Synthetic output that can reveal protected roadmap truth.
- Unapproved contents of the suitcase.
- General artifact cataloging that belongs in `canon/artifacts/`.

## Privacy Rules

1. Do not mirror this material into `docs/writers-room/`.
2. Do not expose this material to `.claude/agents/` unless the user explicitly invokes private roadmap work.
3. Do not treat symbolic interpretation as canon fact.
4. Preserve reveal order.
5. Keep user-held secrets sealed until explicitly promoted.
