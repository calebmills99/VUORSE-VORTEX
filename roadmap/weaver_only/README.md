# Weaver-Only Roadmap

## Purpose

This folder is for the deepest user-held roadmap notes: material that may guide the project but should not be exposed to writers room agents, public canon, ordinary retrieval, or synthetic output without explicit permission.

Weaver-only means sealed by default.

## Use This Folder For

- Private user-held structural truths.
- Long-range series architecture not ready for room access.
- Endgame, recurrence, cosmology, or reveal logic requiring human approval.
- Notes that should guide restraint rather than generation.
- Questions only the Weaver should answer.

## Do Not Use This Folder For

- Public-facing documentation.
- Writers room materials.
- Claude Code subagent instructions.
- Generated JSONL intended for user reveal.
- Any material that can be safely placed in a less restricted roadmap folder.

## Access Rules

1. Do not read this folder unless the user explicitly invokes Weaver-only scope.
2. Do not summarize it into other folders.
3. Do not use it to enrich writers room prompts.
4. Do not allow it to become retrieval-visible.
5. Do not promote any note from here without explicit user instruction.

## Promotion Path

Material can move outward only by explicit user approval:

1. `roadmap/weaver_only/`
2. private roadmap lane
3. VUORSE-confidential working note
4. writers room or canon review
5. public/revealable material

Skipping steps risks breaking the mystery architecture.

## Operating Principle

This is not a folder for answers. It is a folder for answers that are not yet allowed to speak.
