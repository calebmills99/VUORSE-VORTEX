# Human nodes (sealed decisions)

Use when a character, faction, or institution can materially change a branch.

## Actor basis

| Basis | When | Research vs roleplay |
|-------|------|----------------------|
| `evidence` | Rich canon dossier exists | Pull canon only; then separate roleplay |
| `mixed` | Partial canon + gaps | Canon first; gaps as assumptions; then roleplay |
| `assumption` | New / thin / user-invented | Skip dossier research; sealed assumption packet → roleplay |

## Seal protocol

1. Freeze a **dossier** from project lore (paths + quotes/paraphrases).
2. Build a **temporal packet**: only claims the actor could know/access at the decision cutoff.
3. Exclude future spoilers, omniscient narrator facts, and off-stage secrets.
4. Roleplay offline from the packet alone. Propose **at least two** actions from a declared decision graph.
5. Adjudicate against world edges in the main sim. Label motives/actions `simulation`.

## Decision graph minimum

```text
Actor: ::NAME::
Cutoff: ::WHEN::
Knows: …
Does not know: …
Options:
  A — …
  B — …
  C (optional) — …
```

Pick a primary action for the main branch; keep at least one alternate branch alive if stakes are high.
