# Labels & provenance

## Rules

1. Prefer `canon` only when a project file or user-declared bible entry supports it.
2. `inference` must name what it rests on ("from Federstahl premise in series bible §5").
3. `assumption` is first-class. Bold new cool shit belongs here until promoted.
4. `simulation` is the engine's output for this run — disposable unless promoted.
5. `counterfactual` marks events that contradict current canon by design.

## Provenance stub

```text
[claim] — label — source
```

Examples:

```text
Wyoming Rift is the last open fissure — canon — md/SLAYVERSE_TV_SERIES_BIBLE.md §5
Federstahl researchers used tachyon lattices — canon — same
If the rancher names his mother in ep 4, Thread resonance spikes — simulation — this run
Assume Weimar occult cell still holds a lattice shard — assumption — user/run premise
```

## Confidence language

- `high` — multi-source canon, low ambiguity
- `med` — single-source canon or strong inference
- `low` — thin inference
- `assumption` — declared premise / invention
